# Audit, 2026-10-27

A second read of everything, three days before the Play application: kernel and CLI, the control
room and the phone app, the website and the written material, and the launch video. The
2026-10-12 audit is closed; nothing from it is repeated here. Each item says what is wrong, why
it matters, and the fix. Severity: **bug** (does the wrong thing), **security** (lets something
through), **gap** (missing guard or test), **stale** (says something untrue), **polish**.

Checked and found clean: no Node 22 breakers; every flight-recorder change since October 12 is
additive and old logs still read; the Garufile schema only gained optional fields; the Gmail
server can only add labels and create drafts; no path around the policy check; all ten Spanish
Garufiles match their English twins rule for rule; version numbers agree everywhere (0.1.0,
build 4); the app asks only for internet and camera; no orange, no ISO or UTC times, no CLI
commands on phone screens; every screen a newcomer can hit (unpaired, unreachable, zero agents,
zero runs, demo, offline) has a written state; types, tests (32 files, 265) and the translation
test are green; every link on the home page resolves.

## K. Kernel, CLI and tools

- **K1 · bug · an offline run never backs off.** A run that ends `offline` (Gemini unreachable
  after its retry, Ollama down, a token renewal that fails) doesn't set `offlineUntil`, and the
  last-run lookup skips offline runs, so the catch-up re-queues every minute for the whole six-hour
  window: a model attempt and an error run each minute (`scheduler.ts:176,212`, `agent.ts:232`,
  `store.ts:185`). Set `offlineUntil` on an offline result; test it.
- **K2 · bug · Nudge after a late wake posts a false alarm.** A catch-up doesn't say when the run
  was due and Nudge takes "today" from the clock; an 11 PM check caught up at 12:15 AM searches
  tomorrow's commits (`scheduler.ts:187,221`). Hand the run its due time; Nudge uses it.
- **K3 · bug · parallel calls renew the same token twice** when Bea files several threads at once
  near expiry: two refreshes, two new server processes, one leaked (`bus.ts:253,278`). One
  in-flight renewal per server.
- **K4 · bug · a failed renewal kills the run** outside the try, so the approved call is recorded
  as requested but never resulted (`bus.ts:254` vs `:267`). Make it a tool error.
- **K5 · gap · an empty model answer is recorded as ok.** A safety block, a token-limit stop or a
  bad body becomes `content: []`, read as "nothing to do" (`gemini.ts:110-139`, `agent.ts:188`).
  Read `stopReason`; throw on a blocked prompt.
- **K6 · gap · Ollama calls have no timeout** (`ollama.ts:89`); only Gemini got one.
- **K7 · security (low) · a secret inside a remote server's URL** would reach the recorder on a
  sign-in error (`bus.ts:95,105`); the October 12 fix covered arguments, not URLs.
- **K8 · gap · the fetch tool buffers a whole response** before trimming, no byte cap
  (`mcp-fetch/tools.ts:124`). Read up to 1 MB and stop.
- **K9 · security (low, suspected) · the fetch tool resolves a host twice**, once to check it's
  public and once to fetch (`tools.ts:100,111`); the host allowlist mitigates it.
- **K10 · stale · Atlas's header says creating an issue always asks**; since commit 42ea81b the
  learned `allow` sits above the `ask`, which is dead and which `garu validate` flags on both
  editions (`agents/atlas/Garufile.yaml:5-6,50-54`, `why.md:73`).
- **K11 · stale · the test count** is 250 in CLAUDE.md and 230 in why.md; it is 265.
- **K12 · polish · the terminal still prints UTC** for grant expiry, and the grant's "until" is
  baked into the recorder in UTC, which the control room shows (`index.ts:183,468,489,507`,
  `grants.ts:136`).
- **K13 · gap · `garu up` with a paused ask waits up to thirty minutes on Ctrl-C** and schedules
  agents that still need a sign-in (`index.ts:179-186,218-221`).
- **K14 · bug (low) · a Spanish Mac gets English service logs**: the language is read before
  `.env` loads and the launchd plist sets none (`i18n.ts:16`, `service.ts:56`).
- **K15 · gap · model options reach Gemini and Claude and are ignored**; only Ollama reads them,
  although the schema promises pass-through (`gemini.ts:90`, `anthropic.ts:14`, `garufile.ts:208`).
- **K16 · polish · a throwing scheduler hook is an unhandled rejection** that exits the service
  mid-run (`scheduler.ts:148`).
- **K17 · polish · in demo mode a visitor can still dismiss suggestions, revoke grants and create
  24-hour grants** (`ui-server.ts:311`); the twenty-minute reset bounds it.
- **K18 · polish · every refresh re-reads every run log** (`store.ts:138-153`), several times a
  second while an agent works; Tick adds eight files a day. Cache the summary by path and mtime.
- **K19 · polish (suspected) · two fast "Run now" clicks both pass the busy check**
  (`ui-server.ts:142,346`).
- **K20 · polish · three Spanish Garufiles link the Spanish Google guide, two the English one.**
- **K21 · polish · any language code is accepted**; an unknown one silently falls back
  (`garufile.ts:195`).
- **K22 · gap · `garu up --notify` pushes still carry CLI commands and no link** (`index.ts:887`)
  while `garu ui` pushes were fixed on October 12.
